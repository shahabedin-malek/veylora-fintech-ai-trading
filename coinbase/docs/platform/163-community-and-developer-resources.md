# Community and Developer Resources

Use these resources to ask questions, report issues, and contribute to x402.

## Get help

Join the [CDP Discord](https://discord.com/invite/cdp) to ask questions, share what you're
building, and talk to the team shipping x402 support in the CDP SDK. For common product and
integration questions, check the [FAQ](/x402/support/faq).

## Protocol source and issues

The [x402 Foundation repository](https://github.com/x402-foundation/x402) contains the protocol
specifications, payment schemes, extensions, and framework-agnostic SDKs. Use its
[issue tracker](https://github.com/x402-foundation/x402/issues) for protocol bugs and proposals.
For governance, membership, and working groups, see the
[x402 Foundation](/x402/support/x402-foundation).

## CDP SDK source and issues

The [CDP SDK repository](https://github.com/coinbase/cdp-sdk) contains CDP-managed wallet and
facilitator integrations for x402. Use its
[issue tracker](https://github.com/coinbase/cdp-sdk/issues) for CDP SDK bugs and feature requests.
Its [runnable examples](https://github.com/coinbase/cdp-sdk/tree/main/examples) back the code
samples throughout these docs.
