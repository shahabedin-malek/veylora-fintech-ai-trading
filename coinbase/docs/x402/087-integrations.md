# Integrations

Integrations connect x402 payments and service discovery to platforms where you build and run
agents. Use one when your agent platform provides its own payment workflow instead of connecting an
agentic account directly.

<Card title="Amazon Bedrock AgentCore" icon="cloud" href="/x402/integrations/amazon-bedrock-agentcore">
  Give an AgentCore agent access to x402 services through an AWS Payment Manager and Coinbase CDP
  connector.
</Card>

<Card title="Payment Acceptance API" icon="sliders" href="/x402/integrations/payment-acceptance-api">
  x402-enable a merchant checkout built on Payment Acceptance so agents can authorize payment
  sessions directly.
</Card>

## What to read next

[Set up Amazon Bedrock AgentCore](/x402/integrations/amazon-bedrock-agentcore) to connect an
AgentCore agent to the x402 Bazaar and CDP Facilitator, or
[x402-enable Payment Acceptance](/x402/integrations/payment-acceptance-api) to let agents pay
through your existing checkout.
